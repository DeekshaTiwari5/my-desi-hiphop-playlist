# Desi Hip-Hop Radio 🎧🔥

A modern **Desi Hip-Hop radio website** built around the energy, culture, beats, and stories of Indian Hip-Hop.

## 🎵 About

Desi Hip-Hop Radio is a music-focused web experience where users can discover and listen to Desi Hip-Hop through a curated YouTube playlist.

The website combines a street-inspired visual style with a simple radio-style listening experience.

## ✨ Features

- 🎧 Desi Hip-Hop music playlist
- ▶️ YouTube playlist integration
- 📻 Radio-style music experience
- 🎤 Desi Hip-Hop inspired hero section
- 📱 Responsive design for mobile, tablet, and desktop
- ⚡ Fast and lightweight UI
- 🎨 Modern street-inspired design
- 🔗 Easy playlist management

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- YouTube Embed / Playlist
- Responsive Web Design
